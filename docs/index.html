三步就好

两台手机都装上，一台给人看，一台看别人

1

两台手机都装 App

下载安装包，各自装好，用同一个账号登录。

2

「让对方看我的屏幕」的那台

打开「我的 → 让对方看我的屏幕」，点「让对方连进来」，系统问是否允许录屏时点「立即开始」。

3

另一台点进去看

回到「手机」页，点对方那台设备，画面就出来了。直接点、直接滑都行。

试试看

下载安装包，两台手机都装上，五分钟后就能连起来
